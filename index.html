Click Handshake above to begin the camera/barcode handshake.

After the handshake, play the sample game or replace the code in the textarea with a new game. Only one person needs to paste it: whoever clicks Play first instantly transmits and launches it on both phones.

To switch games later, both players must click Back to return to the code screen together.
